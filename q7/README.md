# Question 7: MERN Shopping Cart with Admin & User Sites (2-Level Category)

## Description
A complete MERN stack Shopping Cart application featuring 2-Level Category Hierarchy (Parent Main Category -> Subcategory) with dedicated Admin and User interfaces.

## Features
- **2-Level Category Architecture:** Supports Main Categories (Level 1) and Subcategories (Level 2).
- **Admin Site:**
  - Category Management: Create 1st level main categories and 2nd level subcategories.
  - Product CRUD: Create products mapped to both main category and subcategory, set price, image, stock, and description.
- **User Site:**
  - Interactive sidebar filtering by 2-level category hierarchy.
  - Shopping Cart: Add items, update quantities, dynamic cart total calculation, and simulated checkout.

## How to Run
1. Navigate to `q7` directory:
   ```bash
   cd q7
   ```
2. Start server:
   ```bash
   node server.js
   ```
3. Open `http://localhost:3007`.
