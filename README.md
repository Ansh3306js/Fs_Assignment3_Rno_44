# Full Stack MERN Assignment Solutions

This repository contains complete, functional solutions for all 8 Full Stack (MERN / Express / React / Sequelize / MongoDB) assignment questions.

Each solution is placed in its respective directory (`q1` to `q8`), structured cleanly, fully commented, and ready to run.

---

## 🚀 How to Run Any Question

To run any question, navigate to its directory and start the Node server:

```bash
# Example for Question 1
cd q1
node server.js

# Example for Question 4
cd q4
node server.js

# Example for Question 8
cd q8
node server.js
```

Each server starts independently on its assigned port (3001 to 3008) and opens in your browser!
