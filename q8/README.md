# Question 8: Student CRUD Application using Sequelize

## Description
A Full Stack web application providing full CRUD (Create, Read, Update, Delete) operations for a Student collection using Express, Sequelize ORM (with SQLite), and React.js.

## Features
- **Sequelize ORM & SQLite:** Model definitions with automatic database synchronization and zero setup required.
- **RESTful API:** Endpoints for fetching, creating, updating, searching, and deleting student records.
- **React Frontend:**
  - Dynamic student table with real-time search filtering.
  - Interactive modal for adding and updating student records.
  - One-click deletion with confirmation dialogs.

## How to Run
1. Navigate to `q8` directory:
   ```bash
   cd q8
   ```
2. Start server:
   ```bash
   node server.js
   ```
3. Open `http://localhost:3008`.
